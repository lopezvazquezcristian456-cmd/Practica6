Etiquetas principales de los formularios

< form >

¿Qué es?

Es la etiqueta que define el formulario. Todo lo que esté dentro de ella formará parte del envío de datos.

Atributos importantes:

action URL donde se enviarán los datos.

method Método de envío (GET o POST).

< label >

¿Qué es?

Define una etiqueta descriptiva para un campo del formulario.

¿Por qué es importante?

Mejora la accesibilidad. Permite que al hacer clic en el texto se active el campo relacionado.

< input >

¿Qué es?

Permite crear diferentes tipos de campos.

Tipos comunes: text, password, email, number, checkbox, radio, submit, date.

< textarea >

¿Qué es?

Permite ingresar texto largo (comentarios, mensajes, descripciones).

Atributos importantes: rows, cols.

< button >

¿Qué es?

Crea un botón dentro del formulario.

Tipos: submit, reset, button.

< select > y < option >

¿Qué es?

Crea una lista desplegable.

< fieldset > y < legend >

¿Qué es?

Agrupa elementos relacionados; Define un título para el grupo.
